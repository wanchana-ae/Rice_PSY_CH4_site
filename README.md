# Rice PSY genes and methane emission — results site

หน้ารายงานผลเบื้องต้น: ตระกูลยีน PSY ในข้าว ความผันแปรตามธรรมชาติที่ promoter
การทดสอบกับค่าการปล่อย CH₄ และข้อเสนอการออกแบบแก้ promoter ของ OsPSY2

เว็บ: https://wanchana-ae.github.io/Rice_PSY_CH4_site/

ที่มาของคำถาม: Shi, Ercoli et al. 2026 *Nature Communications* 17:2028
([doi:10.1038/s41467-026-68640-9](https://doi.org/10.1038/s41467-026-68640-9))

## หมายเหตุสำคัญ

- **เป็นผลเบื้องต้น ยังไม่ผ่านการตรวจทาน โปรดอย่าอ้างอิง**
- ผลที่ไม่พบความสัมพันธ์หมายถึง **ข้อมูลชุดนี้ยังไม่มีกำลังพอจะตอบ** ไม่ได้แปลว่ายีน PSY
  ไม่เกี่ยวกับมีเทน — ดูตาราง minimum detectable effect ในหัวข้อที่ 4
- หน้านี้แสดงเฉพาะ **ผลสรุประดับรวม** ไม่มีค่าฟีโนไทป์รายสายพันธุ์ ไม่มีรหัสสายพันธุ์
  และไม่มีจีโนไทป์รายสายพันธุ์
- การวิเคราะห์ cis-element และการออกแบบ guide เป็นผลเชิงคำนวณ ยังไม่ได้ทดสอบในห้องปฏิบัติการ
