# Rice PSY genes and methane emission — results site

หน้ารายงานผลเบื้องต้น: **ตระกูลยีน PSY ในข้าว และความผันแปรตามธรรมชาติที่ promoter**

> **ขอบเขตปัจจุบัน (2026-11-06)**: การทดสอบความสัมพันธ์กับค่าการปล่อย CH₄
> และข้อเสนอการออกแบบแก้ promoter **ถูกถอดออกจากหน้าเว็บชั่วคราว**
> ระหว่างรอตรวจสอบที่มา หน่วย และวิธีวัดของข้อมูลฟีโนไทป์ CH₄

เว็บ: https://wanchana-ae.github.io/Rice_PSY_CH4_site/

ที่มาของคำถาม: Shi, Ercoli et al. 2026 *Nature Communications* 17:2028
([doi:10.1038/s41467-026-68640-9](https://doi.org/10.1038/s41467-026-68640-9))

## หมายเหตุสำคัญ

- **เป็นผลเบื้องต้น ยังไม่ผ่านการตรวจทาน โปรดอย่าอ้างอิง**
- หน้านี้แสดงเฉพาะ **ผลสรุประดับรวม** ไม่มีรหัสสายพันธุ์ และไม่มีจีโนไทป์รายสายพันธุ์
- ตัวแปรเรียกจาก WGS แบบ raw ที่ยังไม่ผ่านการกรองระดับชุดข้อมูล และนับเทียบกับจีโนม
  อ้างอิง Nipponbare ซึ่งหลายตำแหน่งต่างจากพันธุ์ส่วนใหญ่ในคอลเล็กชัน
- ยังไม่มีข้อมูลระดับการแสดงออก จึงยังเชื่อมความผันแปรที่ promoter กับปริมาณ transcript ไม่ได้
